# ai-cost-control

Классификация, теги, summaries, простые quiz — дешёвые модели. Сильные модели — сложный debugging, архитектура, high-risk review. Передавай релевантные chunks, не всю историю; кэшируй по версии prompt/model/input если безопасно. Учитывай токены, latency, retries, fallback, версию prompt и фактическую цену. Лимитируй бюджет/повторы. Не понижай модель для рисков данных, sandbox или достоверности обучения. Коэффициенты пользователя — ориентиры, проверяй usage telemetry.
