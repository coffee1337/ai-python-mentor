# ai-cost-control

Классификация, теги, summaries, простые quiz — дешёвые модели. Сильные модели — сложный debugging, архитектура, high-risk review. Передавай релевантные chunks, не всю историю; кэшируй по версии prompt/model/input если безопасно. Учитывай токены, latency, retries, fallback, версию prompt и фактическую цену. Лимитируй бюджет/повторы. Не понижай модель для рисков данных, sandbox или достоверности обучения. Коэффициенты пользователя — ориентиры, проверяй usage telemetry.

Ориентиры по коэффициентам (качество × цена): ultra_cheap — space-bunny (×0.001), mimo-v2.5 (58%×0.05), deepseek-v4.1-flash (105%×0.1), composer-2.5-fast (100%×0.3), glm-5.3-flash (111%×0.3), minimax-m3 (79%×0.3); cheap — muse-spark-1.3 (126%×0.07), muse-spark-1.2 (105%×0.07), gpt-6-luna (100%×0.38), gpt-5.6-luna (100%×0.5), deepseek-v4-pro (95%×0.5), qwen3.8-flash (105%×0.7); balanced — grok-4.7 (124%×0.5), grok-4.6 (116%×0.5), grok-4.5 (103%×0.5), hy4-preview (118%×1), gpt-5.6-terra (111%×1.3), glm-5.3 (118%×1.5), gemini-3.8-flash (108%×2), claude-sonnet-5 (100%×2), kimi-k3 (116%×2.5), gpt-6-sol (130%×3), gpt-5.6-sol (124%×4); premium — gpt-6.1-sol (×3), claude-opus-5 (134%×4), claude-fable-5.1 (139%×8), gpt-6-astra (139%×10).

Главный вывод по коэффициентам: muse-spark-1.3 (126% при 0.07) и grok-4.7 (124% при 0.5) дают качество уровня GPT при цене в 6-40 раз ниже. Эффективность (качество/цена): muse-spark-1.3 ~1800, deepseek-v4.1-flash ~1050, grok-4.7 ~248, gpt-5.6-sol ~31, gpt-6-astra ~14. Поэтому premium-GPT оправдан только там, где вызовов единицы и цена ошибки высока (security, необратимые миграции, финальное решение), а не на ежедневной рутине.

Ограничения: grok-4.x и deepseek имеют 500k контекста против ~1M у gpt/claude/glm/gemini/kimi — на больших репозиториях это ограничивает выбор или требует резать вход. GLM 5.3 силён на длинном контексте и русском тексте. Внешние модели (grok, muse, deepseek, glm) — сверяй факты о проекте по локальному коду, не полагайся на память модели.

Самая большая экономия — не цена токена, а число вызовов: не запускай агента без сигнала, режь контекст до нужных chunks, кэшируй неизменяемый prompt, ограничивай retry и budget. Апгрейд модели (muse-spark → grok-4.7 → gpt-6.1-sol) почти всегда дешевле второго цикла отладки на дешёвой модели. Фактические цены сверяй по usage telemetry провайдера.
