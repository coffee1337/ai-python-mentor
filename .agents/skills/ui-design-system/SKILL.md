# ui-design-system

Текущий язык проекта: спокойный editorial. Бумажный фон, зелёный акцент, крупная антиква в заголовках, тонкие линии вместо тяжёлых карточек, много воздуха. Не вводи новый визуальный язык без явного согласования.

Токены живут в `globals.css` как переменные (`--ink`, `--muted`, `--paper`, `--green`, `--line`). Новые цвета и размеры добавляй как токены, а не литералами по одному месту.

Честность данных: не рисуй графики и проценты без реальных данных за ними. Masterness — не истина, а модель; assisted и independent показывай раздельно. Не добавляй мотивационные счётчики, которые не измеряют обучение.

Доступность — часть дизайна, а не финальная проверка: контраст, размер цели касания, видимый фокус, логический порядок заголовков, работа без мыши, учёт `prefers-reduced-motion`.

Каждое решение сопровождай состояниями: empty, loading, error, success, disabled, и поведением на мобильном.

Запрещено: системные шрифты по умолчанию (`Arial`, `Helvetica`, без заданной гарнитуры). Используй подключённые.variable-шрифты из `layout.tsx` и токены `--sans`/`--serif`/`--mono`. Файл стилей пиши структурно, с переносами и комментариями-разделителями; минифицированный вручную CSS на этом проекте недопустим.

Перед сдачей проверь, что каждый `className` из JSX имеет правило в CSS, и что в исходниках нет `????` вместо русского текста — потеря кодировки проходила незамеченной.
