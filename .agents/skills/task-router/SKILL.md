# task-router

Определи класс задачи. Тривиальная/локальная — без делегации или implementer на самой дешёвой пригодной модели. Обычная фича — implementer, tester если есть риск поведения. Сущности/миграции/границы — architect → implementer → целевой tester/reviewer. Sandbox/auth/приватность/данные — security-reviewer и сильная модель. Эскалируй после двух неудачных целевых циклов или при высоком риске. Не дублируй анализ, передавай только нужные контекст и файлы. При параллельности назначай владельца файлов. Закрывай задачу проверяемым результатом.
