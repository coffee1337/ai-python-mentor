# code-review

Порядок: корректность/регрессии → безопасность/данные → контракты/ошибки → тесты → поддерживаемость. На finding укажи severity, место, условия, ущерб и проверку. Не выдавай гипотезу за факт и не давай общие советы без привязки. Укажи запущенные проверки и просмотренные статически области.
