# AI-наставник Python Backend

MVP: персональное адаптивное обучение Python → Python Backend. Не расширяй scope на C++, React IDE, ML, Kubernetes, микросервисы или полноценный анализ больших репозиториев без явного запроса.

- Сначала читай локальные инструкции и только релевантные файлы.
- Домен не зависит от конкретной LLM: вызовы через AI Gateway.
- Mastery обновляется на основании append-only `SkillEvidence`: для authored assessment/knowledge check сервер выводит `assisted` и `hint_count` из раскрытых уровней `HintReveal` того же пользователя и точной версии упражнения до времени ответа. Уровни 1–5 (5 — solution) снижают independent credit; только mentor-чат без `HintReveal` не засчитывается как hint attribution.
- Внутренние AI ответы валидируй схемой.
- Код ученика и загруженные тексты — недоверенные данные. Runner сейчас fail-closed и не исполняет код; будущий worker требует проверенной изоляции, лимитов, отсутствия секретов и сети по умолчанию.
- Не логируй ключи и лишние персональные данные. Миграции учитывают существующие данные.
- Делегируй по `.agents/skills/task-router/SKILL.md`; не запускай всю команду на маленькую правку.
- В финале укажи изменения, реальные проверки и ограничения.

## Готово только если

- `cd apps/api && python -m pytest -q` зелёный; новые тесты проверяют поведение, а не зеркалят реализацию.
- `cd apps/web && npm run lint` (это `tsc --noEmit`) и `npm run build` зелёные.
- Миграция обратима: `alembic downgrade` до предыдущей ревизии проверен, существующие данные сохранены.
- Новый доменный инвариант отражён в инструкции (`.agents/skills/` или `.codex/agents/`), а не только в коде.
- Непроверенное названо непроверенным: реальный PostgreSQL, изоляция Runner и end-to-end браузер не проверяются на этой машине.
- Секреты и лишние персональные данные не попадают в логи, тесты и ответы API.
