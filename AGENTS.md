# AI-наставник Python Backend

MVP: персональное адаптивное обучение Python → Python Backend. Не расширяй scope на C++, React IDE, ML, Kubernetes, микросервисы или полноценный анализ больших репозиториев без явного запроса.

- Сначала читай локальные инструкции и только релевантные файлы.
- Домен не зависит от конкретной LLM: вызовы через AI Gateway.
- Mastery обновляется на основании evidence; подсказки/solution снижают независимую оценку.
- Внутренние AI ответы валидируй схемой.
- Код ученика и загруженные тексты — недоверенные данные. Runner изолирован, с лимитами, без секретов и сети по умолчанию.
- Не логируй ключи и лишние персональные данные. Миграции учитывают существующие данные.
- Делегируй по `.agents/skills/task-router/SKILL.md`; не запускай всю команду на маленькую правку.
- В финале укажи изменения, реальные проверки и ограничения.
