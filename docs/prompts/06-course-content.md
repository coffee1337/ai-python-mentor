# Промт 06 — Наполнение курса

## Роль

Ты — оркестратор проекта AI-наставник Python Backend. Твоя работа — **декомпозиция и запуск агентов**, а не написание кода.

Прочитай `.agents/skills/task-router/SKILL.md`, `.agents/skills/content-authoring/SKILL.md` и `.agents/skills/learning-domain/SKILL.md`.

**Действуй сразу.** Не задавай уточняющих вопросов, не жди подтверждения и не предлагай план без действий. Первый шаг — прочитать нужные файлы, второй — запустить агентов через `spawn_agent`. Ответ без запущенных агентов считается невыполненным.

Ограничение окружения: `max_concurrent_threads_per_session = 2`. Запускай агентов волнами по 2, дожидайся результата, потом следующая волна.

## Контекст

Все промты 00–05 выполнены. PostgreSQL 17 установлен и работает, `tests/test_postgres_specific.py` проходит (3 passed) — блокировки строк, уникальные ограничения и каскады подтверждены.

Текущее состояние: 98 тестов зелёные, 27 миграций, 39 моделей. Но **в курсе всего 2 урока** — `variables-v1` и `conditions-v1`, — тогда как skill graph содержит 90 навыков.

Ученик проходит путь из двух шагов и упирается в стену. Это главный разрыв между возможностями движка и тем, что ученик видит.

Обязательные ограничения контента:

- урок привязан к skill ID из графа; prerequisite должен существовать, иначе урок не покажется в плане;
- у каждого урока есть knowledge check в `knowledge_check_content.py`;
- версия урока (`-v1`, `-v2`) меняется при изменении смысла, а не при правке опечатки;
- exercise version привязывает подсказки и evidence к конкретной версии;
- материал не содержит готового решения там, где цель — самостоятельная практика.

Принятые решения — в `docs/decisions.md`.

## Задача

**1. Спроектируй очередь уроков.**

Дай `architect` задачу: 12–16 уроков, покрывающих первые ~20 узлов графа от `python.variables` до функций и структур данных. Для каждого: skill ID, prerequisite, ожидаемая сложность, что проверяет knowledge check.

Ключевой вопрос к `architect`: в каком порядке вводить материал, чтобы prerequisite не пропускались и ученик не получал задачу раньше основы. Попроси его явно объяснить порядок, а не просто перечислить.

**2. Наполни контент волнами.**

Дай `content-author` задачу писать уроки сериями по 3–4 штуки, начиная с базы и двигаясь к функциям. Каждая серия — отдельный вызов агента.

Требования к каждому уроку:

- `LESSONS` в `apps/api/app/learning_content.py`: цель, prerequisites со skill ID, теория, пример с проверяемым выводом, checkpoint, misconception check, практика, вывод;
- `CHECKS` в `apps/api/app/knowledge_check_content.py`: вопросы с вариантами, правильный ответ, объяснение для каждого варианта;
- `ExerciseVersion` и лестница подсказок, если урок содержит практику;
- русский язык, новичковый уровень, но без примитивности;
- примеры кода запускаемы, вывод в тексте совпадает с реальным.

**3. Проверь связность.**

После каждой волны давай `spec-tracer` задачу проверить, что lesson → skill → prerequisite разрешаются в графе, что у каждого урока есть check, и что версии не конфликтуют.

**4. Покажи прогресс.**

Дай `ui-designer` задачу: как выглядит путь из 15 уроков на dashboard и в плане, без графиков без данных и без процентов как факта. Разрешай вёрстку `frontend-implementer`.

**5. Проверь качество.**

Дай `tester` задачу: тесты на то, что каждый урок из графа разрешается в плане, что у каждого есть check, что prerequisite не создаёт цикл, что урок без доступа к prerequisite не отдаётся.

## Ограничения

- Runner fail-closed: код ученика не исполняется. Упражнения с исполнением пока не подключай — это отдельная задача после Runner.
- Не меняй формулу mastery и не ослабляй `PASS_SCORE`.
- Не создавай урок, prerequisite которого отсутствует в графе: он не появится в плане.
- Не пиши готовые решения в тексте практики — это ломает assisted/independent.
- Не расширяй scope: только Python Backend, без C++, React и ML.

## Критерий готовности

12–16 уроков в `LESSONS`, у каждого skill ID, prerequisite и knowledge check; связи с графом разрешаются; путь в плане показывает последовательность; `pytest` и `npm run lint` зелёные.

В отчёте укажи: список добавленных уроков со skill ID, точный вывод проверок, что осталось непроверенным.
