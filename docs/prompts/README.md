# Промты реализации

Каждый промт — один новый чат. Копируй текст блока целиком, включая заголовок.

## Как это работает

Ты ведёшь чат с GPT 6 Luna. Промт просит его **делегировать работу агентам**, а не писать код напрямую. Агенты лежат в `.codex/agents/`, скиллы в `.agents/skills/` — Luna прочитает их сама.

Порядок промтов важен: каждый следующий опирается на результат предыдущих. Не перескакивай.

## Если Luna останавливается и задаёт вопрос

Напиши ей ровно это:

> Не задавай уточняющих вопросов и не предлагай план без действий. Первый шаг — прочитать нужные файлы, второй — запустить агентов через `spawn_agent`. Ответ без запущенных агентов считается невыполненным. Параллелизм ограничен двумя агентами: запускай волнами по 2. Все предыдущие промты уже выполнены, не проверяй их.

Останавливаться без действий — не результат, даже если агент написал разумный план.

## Что делать, если Luna говорит, что запустила агентов

Иногда агенты отменяются на середине. Если в ответе нет изменённых файлов и вывода команд — попроси продолжить:

> Продолжай с того места, где остановился. Проверь `git status` — если там есть твои незакоммиченные изменения из предыдущих шагов, не сбрасывай их. Доведи задачу до конца и покажи точный вывод команд.

## Проверки на этой машине

**Docker, Compose и WSL2 не работают.** Виртуализация недоступна, `docker version` не соединяется с daemon, дистрибутивов WSL нет.

Работает: `python -m pytest` (33 теста на SQLite), `npm run lint`, `npm run build`, `alembic check` на SQLite.

**PostgreSQL 17 установлен нативно** и работает. Промт 05 выполнен: служба `postgresql-x64-17` в статусе Running, порт 5432 отвечает, `tests/test_postgres_specific.py` проходит при `RUN_POSTGRES_TESTS=1` и `DATABASE_URL` из `.env.example` (3 passed). Блокировки строк, уникальные ограничения и каскады подтверждены на настоящей БД.

## Про PostgreSQL — важно

Все 33 теста идут на SQLite. Функции, специфичные для PostgreSQL, не проверяются: `with_for_update()` в `mentor.py` и `skill_evidence.py`, внешние ключи, уникальные ограничения.

**Промт 05 это чинит.** PostgreSQL 17 ставится нативно через `winget` и работает без виртуализации — в отличие от Docker и WSL2. Расширение VS Code с контейнерами здесь не поможет: ему тоже нужна виртуализация.

Промты 02, 03 и 04 выполнялись уже после установки PostgreSQL, поэтому миграции и блокировки проверены на настоящей базе.

## Что делать, если агент ответил отказом

Инструкции проекта запрещают часть вещей намеренно: включить Runner, выдавать готовое решение, принимать `user_id` от клиента, рисовать проценты mastery как факт.

Это не ошибка промта. Скопируй Luna ответ: «Это ожидаемо, предложи обходной путь, который не нарушает инвариант», — и она переключится на правильную реализацию.

Отдельный случай — сообщение про незакоммиченные изменения. В репозитории их много и они твои: прошлые сессии не коммитились. Ответ «не буду сбрасывать, чтобы не потерять вашу работу» — это осторожность, а не блокировка. Напиши:

> Незакоммиченные изменения в репозитории — это моя текущая работа, их не нужно откатывать и не нужно обсуждать. Продолжай свою задачу.
